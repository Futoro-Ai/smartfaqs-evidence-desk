# WebMCP Challenge Entry

## What We Built

SmartFAQs Evidence Desk is a synthetic knowledge workspace where a person and
an agent investigate the same source material together. The agent can select a
source, verify readiness, search bounded evidence, inspect individual chunks,
and stage an evidence-backed answer. The person remains responsible for final
approval.

## Why WebMCP

Without WebMCP, an agent must infer controls and scrape visual text. With
WebMCP, the page exposes a narrow evidence workflow with explicit schemas while
keeping every important state change visible in the human interface.

## New Work

This standalone application and its WebMCP integration were created during the
2026 WebMCP Challenge submission period. It does not publish or depend on any
private SmartFAQs repository.

## Demonstrated Workflow

1. List and select a synthetic policy source.
2. Check whether it is ready for evidence-backed use.
3. Search relevant text and table chunks.
4. Read the bounded source chunks.
5. Stage an answer with validated evidence references.
6. Let the human approve or reject the staged answer.
7. Export a sanitized evidence packet.

The same capability implementations are also exposed through a fixed MCP
server endpoint for clients that operate independently of the open page.
